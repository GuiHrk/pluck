# pluck

> Gerencie projetos com muito mais estilo Centralize tarefas, equipes e fluxos de trabalho em uma plataforma moderna, e rápida. 

---

Gerenciar tarefas em grupo se tornou fator crucial em entregas de projetos, e até mesmo na própria gestão. A plataforma tem foco em ajudar de forma simples, porém funcional na gestão de tarefas em grupo. 


🔗 https://pluck-woad.vercel.app/


## Tecnologias Utilizadas

- **Frontend:** HTML, CSS, Bootstrap, JS
- **Backend:** Springboot, PostgreSQL
- **Deploy:** Vercel, Railway
